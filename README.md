# AI-Student-Assistant-Chatbot
A Python-based AI Student Assistant chatbot that answers predefined questions about AI, Machine Learning, Python, skills, projects, and placements
## GIST Internship - Task 1

This project is a simple Python-based AI Student Assistant Chatbot developed as part of the GIST 4-Week Remote Internship Program.

## Project Description

The chatbot answers predefined questions related to Artificial Intelligence, Machine Learning, Python, student skills, projects, and placement preparation.

It uses user input handling, conditional statements, and conversation flow to provide suitable responses.

## Features

- Greeting responses
- Artificial Intelligence information
- Machine Learning information
- Python information
- Student skill recommendations
- Project guidance
- Placement preparation guidance
- Thank-you responses
- Exit command

## Technologies Used

- Python
- Google Colab
- GitHub

## How to Run

1. Open the Python file in Google Colab or a Python environment.
2. Run the program.
3. Enter a question when `You:` appears.
4. The chatbot provides a suitable response.
5. Type `bye` to end the conversation.

## Example

User:
What is machine learning?

Bot:
Machine Learning is a branch of AI where computers learn patterns from data and use them to make predictions or decisions.
